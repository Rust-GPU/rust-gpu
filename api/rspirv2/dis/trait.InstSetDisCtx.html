An instruction set that provides additional context information for disassembly.

Required Methods§

Source

fn add_context(slice: &RawInstSlice, ctx: &mut DisContext)

Add context to the supplied DisContext by modifying the various public members of it.

Only supplies a RawInstSlice instead of a full InstSlice that has been error checked, as to allow disassembly of partially corrupt instructions. Any DecodeError that arrises during decode should be silently ignored. We recommend using slice.iter().try_decode::<CoreInstSet>().skip_errors() to decode instructions from the RawInstSlice.
