Struct InstVec 

Source 
pub struct InstVec<ISA>
where
    ISA: InstEncoding,
{ /* private fields */ }
Expand description

An InstVec works like a Vec<ISA>, but stores instructions in the variable-sized SPIR-V binary form to safe on memory size.

See InstSlice for details.
