pub struct InstRef<'a, ISA>

    ISA: InstEncoding,
{ /* private fields */ }
Expand description

A reference to a valid instruction encoded in a slice of Words.

Call Self::get to get the underlying instruction, as it unfortunately can’t implement Deref.

§Safety

The referenced words must be an encoded instruction that is valid within the ISA instruction set. Encountering an invalid instruction may panic.
