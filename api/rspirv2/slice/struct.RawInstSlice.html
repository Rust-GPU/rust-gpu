Struct RawInstSlice 

Source 
#[repr(transparent)]
pub struct RawInstSlice(pub [Word]);
Expand description

A slice of SPIR-V instructions of an arbitrary instruction set.

Compared to InstSlice, does not specify the instruction set nor require the inner words to be valid instructions in said instruction set.
